Privacy

goui collects no personal data. No account, no analytics, no ads. Nothing leaves your device except the AutoEQ and GitHub release requests described below.

Last updated 15 October 2026. Covers the goui browser extension (v0.1.3 and later) and goui for the Mac.

What goui reads

  • The active tab (extension). goui reads the tab's URL (to verify it is a web page) and title (to display in the panel). It reads no other tabs.
  • Audio. Audio runs through the EQ in memory and plays back immediately. goui never records, stores or transmits audio.

What goui stores locally

All settings stay on your device (in browser extension storage or ~/Library/Application Support/goui on macOS).

  • EQ settings, presets and Sets.
  • The last active tab and graph view.
  • A cached copy of the AutoEQ headphone index (refreshed weekly).
  • The captured tab's title for the current browser session.

Network requests

When you search AutoEQ or pick a headphone, goui fetches the index and profile from GitHub (raw.githubusercontent.com) under the GitHub privacy statement. goui sends no user data with these requests.

Clicking Measure my ear opens eqbyear.com in a new tab under EQByEar's own policy. goui only reads the text you paste back.

On macOS, goui checks GitHub Releases twice a day for updates without sending any user data.

This website
