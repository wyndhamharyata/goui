goui for the Mac

The same parametric EQ for all system audio on your Mac.

goui runs from the menu bar and opens the same panel as the browser extension. One EQ processes Apple Music, Spotify, calls and games at once.

Keep separate layers for your headphone, your ear and your taste, plus Bass, Vocals and Treble sliders. Search the AutoEQ database and watch the live spectrum. A native C and Swift engine processes the audio in real time and stores none of it.

Right-click the menu bar icon to switch Sets without opening the panel, or run goui set "name" from Terminal.

goui starts at login, restarts automatically on crash, and rebuilds the audio path when you switch output devices.

Wide panel

Widen the panel to view Listen, Tune and Library side by side.

Install

One command in Terminal. No admin password required.

curl -fsSL https://raw.githubusercontent.com/wyndhamharyata/goui/main/mac/install.sh | sh

Requires Apple silicon and macOS 26 or later. goui is not signed with an Apple Developer ID yet, so engine updates prompt for audio permission again. Read the Mac guide before installing, including notes on AirPods Spatial Audio.

How it works

Three separate layers for your headphone, your hearing and your taste.

Every headphone colours the sound. AutoEQ measures that frequency response and builds a correction profile to make it neutral. That is the Headphone layer.

Your ears have their own response on top of the headphone. An EQByEar test measures what your hearing still needs. That is the My ear layer.

Taste is the third layer for your own custom bands, alongside Bass, Vocals and Treble sliders. Toggle any layer independently.

All active bands sum in dB, and the auto preamp offsets the highest boost to prevent clipping.

Save a Set to link a headphone preset, ear preset, taste preset and slider values. Updating a preset updates every Set that references it.

Install

Install from the Chrome Web Store for automatic updates.

Or load unpacked

Four steps. No build step or account required.

  1. Download the zip. Get the latest zip from the Releases page and unzip it.
  2. Load the folder. Open chrome://extensions or brave://extensions, enable Developer mode, click Load unpacked, and select the unzipped goui folder.
  3. Pin goui. Click the puzzle piece in the toolbar and pin goui.
  4. Click the icon. Open a tab playing audio and click the goui icon.

See the README for step-by-step screenshots.
