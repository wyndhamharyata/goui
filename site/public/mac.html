What it is

goui for the Mac brings the browser extension's parametric EQ to all system audio. Music, Spotify, calls and games all run through it at once.

Music · Zoom · SafariEvery sound the Mac plays
1 · HeadphoneAutoEQ tunes your headphone to sound neutral
2 · My earEQByEar tunes it to your hearing
3 · TasteYour own bands
Basic tuningBass, Vocals and Treble
PreampKeeps the sum from clipping
YouHear it

Click the menu bar icon to open Listen, Tune and Library. AutoEQ gives your headphone a neutral baseline, EQByEar tunes it to your hearing, and Taste holds your own bands. Each layer has its own switch, and the auto preamp prevents clipping. A native audio engine processes the sound in real time and stores none of it.

Before you install

Install with one command in Terminal. No admin password required.

curl -fsSL https://raw.githubusercontent.com/wyndhamharyata/goui/main/mac/install.sh | sh
  • Requires Apple silicon and macOS 26 or later.
  • Follows the default output device and EQs all system audio.
  • Other system EQs (such as eqMac or SoundSource) stack on top of goui. Run only one at a time.
  • Spatial Audio and head tracking on AirPods and Beats pause while goui plays. See Troubleshooting.
  • macOS asks permission to record system audio. goui processes audio in real time and keeps none of it.
  • goui is not signed with an Apple Developer ID yet, so engine updates prompt for audio permission again.
  • Settings stay in ~/Library/Application Support/goui across updates and uninstall.

Sets

A Set links a headphone preset, an ear preset and a taste preset with the Bass, Vocals and Treble sliders. Pick one on Listen or in Library under Sets. Save each active layer as a preset first, then save the Set. Saving under an existing name replaces it. Editing a preset updates every Set that uses it.

To switch Sets without opening the panel, right-click the menu bar item and pick one from the Sets submenu. You can also run goui set "name" from Terminal, a shortcut or a login item. The engine cannot play a Set with more than 32 active bands, counting the three sliders.

Measure your ear

AutoEQ corrects the headphone. EQByEar measures what your ear still needs on top of it.

2 Run the testeqbyear.com opens in your browser. Since goui already processes browser audio on the Mac, start the test right away.

Troubleshooting

! AirPods and Beats lose Spatial Audio or head trackingmacOS applies Spatial Audio only when apps play directly to AirPods or Beats. Disable Spatial Audio in Control Center while using goui, or quit goui when you want Spatial Audio.
! No sound, or audio bypasses the EQVerify goui is allowed under System Settings > Privacy & Security > Screen & System Audio Recording, then click Restart engine in the menu.
! Unexpected volume changesAnother system EQ (such as eqMac or SoundSource) is running at the same time. Quit one of them.
! goui set says goui is not runningRun goui start and try again. If the panel has not loaded, click Reload panel in the menu.
! An update failedRun goui rollback to restore the previous version, and check goui logs.

Privacy

  • goui processes system audio live in memory, with zero recording, storage, or transmission.
  • All settings, presets, and Sets remain strictly local in ~/Library/Application Support/goui.
  • AutoEQ downloads and update checks run anonymously without sending personal data. See the privacy policy.
