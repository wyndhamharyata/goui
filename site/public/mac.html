goui for the Mac

The same EQ as the extension, for every sound on the Mac. goui lives in the menu bar and opens the same panel as the browser: Listen, Tune and Library, with AutoEQ and EQByEar.

Install with one line in Terminal. No admin password. It asks before installing.

curl -fsSL https://raw.githubusercontent.com/wyndhamharyata/goui/main/mac/install.sh | sh

Before you install

  • Needs Apple silicon and macOS 26 or later.
  • goui EQs every sound on the Mac. It follows the default output. One EQ covers every app. Another system EQ (eqMac, SoundSource) stacks its curve on goui's. Run one at a time.
  • Spatial Audio and head tracking on AirPods and Beats stop while goui plays. See troubleshooting below.
  • macOS asks to let goui record audio. goui EQs the sound on its way out and keeps none of it.
  • goui is not signed by Apple yet. An engine update asks for that permission again. Settings stay in ~/Library/Application Support/goui through updates.

Get started

  1. Turn goui on. Click goui in the menu bar. Press the power button.
  2. Allow audio. macOS asks to let goui record audio the first time. Press Allow. goui keeps none of it.
  3. Play something. Any app. Music, a video, a call.

The panel works the same as in the browser. The live panel on the homepage shows each part.

The menu bar item

  • Click opens and closes the panel.
  • Right-click opens the menu.
  • About goui shows the version of goui.
  • Wide panel widens the panel so Listen, Tune and Library stand side by side. You can also drag the edge.
  • Restart engine rebuilds the audio path. The sound plays briefly without the EQ.
  • Reload panel reloads the panel. The sound carries on.
  • Sets lists saved Sets and ticks the active one. Pick a Set to load it with the panel closed. The submenu appears after saving a Set.
  • Check for Updates… checks GitHub for a newer release.
  • Update to … appears when a release changes the engine. One click installs it and restarts goui.
  • Automatic updates checks twice a day.
  • Quit goui stops it until the next login.

goui updates itself. A panel-only release applies on its own. An engine release waits for Update to …. macOS asks again to record audio. goui checks GitHub for new versions and sends nothing about you.

goui starts at login and restarts after a crash. If the sound stops, it rebuilds the audio path.

From Terminal

The installer puts a goui command in Terminal.

  • goui set "name" loads a Set, same as picking it from the menu.
  • goui start, goui stop, goui restart control the app.
  • goui logs tails the log.
  • goui rollback restores the app from before the last update.
  • goui uninstall removes the app. Settings stay in ~/Library/Application Support/goui.

Measure your ear

Measure my ear with EQByEar opens eqbyear.com in your browser. It turns My ear off so the test hears only the AutoEQ profile. goui already processes the browser audio, so run the test straight away. Copy the result. Press Paste in the My ear tab, paste it, then press Apply and Save.

Troubleshooting

AirPods and Beats sound flat or lose head tracking.

macOS applies Spatial Audio and head tracking only when an app plays straight to AirPods or Beats. goui processes the audio in between, so the effect stops or can sound wrong. Turn off Spatial Audio in Control Center, or quit goui while using them.

No sound, or the sound plays without the EQ.

Check that goui is allowed in System Settings, Privacy & Security, Screen & System Audio Recording. Then pick Restart engine in the menu.

Privacy

goui reads the Mac's audio, runs it through the EQ and plays it back. It never records, stores or sends it. Settings, presets and Sets stay in ~/Library/Application Support/goui. AutoEQ downloads work as in the extension. See the privacy policy. goui checks GitHub for new releases twice a day. That request carries nothing about you.
